# 🚀 SWYNEX – Responsive Landing Page

A modern, stylish, and fully responsive landing page project built with a focus on clean UI, smooth user experience, and responsive web design.

## 🌟 Project Overview

**SWYNEX** is a responsive landing page designed to deliver a modern web experience across desktops, tablets, and mobile devices.

The project focuses on clean design, structured components, and a responsive layout to provide a consistent experience across different screen sizes.

## ✨ Features

- 📱 Responsive design for different screen sizes
- 🎨 Modern and clean user interface
- ⚡ Fast development with Vite
- 🧩 Component-based architecture
- 💻 TypeScript-powered development
- 🌐 HTML and CSS integration
- 🚀 Optimized development workflow

## 🛠️ Tech Stack

- **TypeScript** – Application development
- **HTML5** – Page structure
- **CSS3** – Styling and responsive layouts
- **Vite** – Development and build tool

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/monishwaran-b/SWYNEX-Responsive-Landing-Page.git
```

### 2. Navigate to the Project

```bash
cd SWYNEX-Responsive-Landing-Page
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

### 5. Build for Production

```bash
npm run build
```
